# DT102G - ASP.NET with C#

Database-driven web-based systems based on C#, ASP.NET MVC, Entity framework and SQL server.

In this course, I worked extensively with CRUD applications, login systems, and administration panels. I developed a simple [web shop](https://github.com/albinronnkvist/Course_DT102G_ASPDotNETWithCSharp/tree/main/Webbshop) in ASP.NET with user authentication, role-based access, and full CRUD functionality. The web shop was built using C#, ASP.NET MVC, DAL, Entity Framework, and SQL Server. Additionally, I worked with ER diagrams and table schemas to plan relational databases before implementation.
